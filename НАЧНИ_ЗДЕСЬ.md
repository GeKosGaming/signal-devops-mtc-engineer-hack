# SIGNAL: готовое решение

Публичный main: https://github.com/GeKosGaming/signal-devops-mtc-engineer-hack

1. Полный Ubuntu 24.04 kubeadm-прогон прошёл: https://github.com/GeKosGaming/signal-devops-mtc-engineer-hack/actions/runs/37145316744
2. Команды запуска и ограничения - README.md; соответствие кейсу - docs/REQUIREMENTS.md.
3. Демонстрация - make demo, здоровая canary - make canary; восстановление логов - make log-delivery.
   Проверка отказа конкурирующим операциям и восстановления после сигналов - make operation-check.
4. Проверенные отчёты - evidence/published/. В JSON явно указаны ОС и commit.
5. Четырёхстраничный паспорт - docs/Паспорт.pdf. Редактируемый текст - docs/Паспорт_текст.txt.
6. Архив для загрузки организатору - Коннов.zip: только Ссылка.txt и Паспорт.pdf.
7. Финальный acceptance выполняется после commit документов; package проверяет публичный main и чистоту HEAD.

90/10: stable 360, canary 40 из 400. Восстановление Pod: 6.58 с, ошибок 0/50. После недоступности Loki найдено 20/20 ID; максимальная наблюдённая задержка 39.9 с; дополнительных видимых копий 0. Все этапы здоровой canary 10/25/50/100% прошли. Это измерения одного лабораторного прогона.

Одноузловой стенд не обеспечивает HA при отказе VM; результаты не объявляются production SLA.
