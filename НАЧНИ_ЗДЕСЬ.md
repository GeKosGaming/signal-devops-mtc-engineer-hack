# SIGNAL: порядок работы с комплектом

Публичный проект: https://github.com/GeKosGaming/signal-devops-mtc-engineer-hack

1. Запуск и ограничения - README.md.
2. Соответствие кейсу - docs/REQUIREMENTS.md; решения - docs/DECISIONS.md.
3. Текущие локальные проверки - evidence/local-checks.json (реальная среда и пропуски указаны).
4. Основная приёмка - Actions workflow Ubuntu kubeadm acceptance; полный runtime пока ожидает запуска.
5. Демонстрация - make demo; проверка буфера при недоступности Loki - make log-delivery.
6. Паспорт в docs/ пока содержит исходный NOT_RUN; финальный паспорт обновляется по фактическому отчёту.
7. Архив сдачи Коннов.zip должен содержать только Ссылка.txt и Паспорт.pdf; порядок - docs/SUBMISSION.md.

Исходный архив проекта не является двухфайловым архивом для организатора.
